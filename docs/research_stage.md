# Этап исследования и выбора технологий

## Цель этапа

Целью данного этапа является:

- изучение инструкций и руководств по использованию технологий и оборудования, необходимых для реализации проекта;
- теоретические и экспериментальные исследования по созданию продукта;
- анализ полученных данных.

---

## Основные виды работ

### 1. Выбор методов для решения поставленных задач проекта

Для реализации системы мониторинга усталости и отвлечённости были рассмотрены следующие подходы:

| Задача | Рассмотренные методы | Выбранный метод |
|---|---|---|
| Детекция лица и ключевых точек | Dlib, OpenCV DNN, MediaPipe Face Mesh | **MediaPipe Face Mesh** |
| Оценка открытости глаз | HOG + SVM, CNN-классификатор, Eye Aspect Ratio | **Eye Aspect Ratio (EAR)** |
| Оценка усталости | ML-классификатор, нейросетевая fusion-модель, rule-based score | **Rule-based PERCLOS + EAR** |
| Оценка положения головы | PnP-задача по 3D-точкам, DeepFace, MediaPipe | **PnP (solvePnP) по landmarks** |
| Сглаживание сигналов | Медианный фильтр, EMA, rolling window | **Rolling window + EMA** |

**Обоснование выбора rule-based подхода:**  
На этапе MVP предпочтение отдано интерпретируемым и легко настраиваемым методам. Rule-based модели позволяют быстро итерировать пороги, не требуют размеченных обучающих данных и дают предсказуемое поведение при тестировании.

## Ключевые метрики и алгоритмы

### Eye Aspect Ratio (EAR)

Метрика оценки открытости глаза, вычисляемая по координатам ключевых точек:

```
EAR = (||p2 - p6|| + ||p3 - p5||) / (2 * ||p1 - p4||)
```

- При открытом глазе: EAR ≈ 0.25–0.35
- При закрытом глазе: EAR < 0.18–0.20

### PERCLOS

Процент времени, в течение которого глаза были закрыты (EAR ниже порога) за скользящее окно 30–60 секунд:

```
PERCLOS = (кадры с закрытыми глазами) / (всего кадров в окне)
```

- PERCLOS > 0.15 — признак усталости
- PERCLOS > 0.30 — высокий уровень усталости

### Calibration

Для устранения индивидуальных различий (форма глаз, очки, освещение) предусмотрена калибровка baseline:

- 30–60 секунд в нормальном состоянии
- Сохранение персональных значений EAR, head pose, длительности морганий

## Результат этапа

По итогам исследования:

1. Определён **методологический подход** — rule-based CV-движок на основе EAR, PERCLOS и head deviation.
2. Выбран и обоснован **программный стек** (Python, OpenCV, MediaPipe, NumPy, Pydantic, FastAPI).
3. Сформулированы **требования к оборудованию** — стандартная веб-камера без необходимости GPU.
4. Спроектирована **архитектура CV-модуля** с чётким разделением на слои: camera → landmarks → metrics → temporal → state → API.
5. Определены **ключевые алгоритмы** и диапазоны пороговых значений для дальнейшей калибровки.
